# Milanjeet Singh — Portfolio

Minimalist responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy
Push the project to GitHub, then import the repository into Vercel.
